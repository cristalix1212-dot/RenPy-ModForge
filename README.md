Ren'Py Mod Builder
Визуальный конструктор модов для Ren'Py, который работает прямо в браузере. Собираешь сцену мышкой, а на выходе получаешь настоящие файлы .rpy, которые можно закинуть в игру. Писать код не нужно.
Всё живёт в одном HTML-файле, ничего устанавливать не надо. Для работы нужен интернет: библиотеки (React, Tailwind, Lucide, JSZip) подгружаются с CDN.
Что умеет
Сценарий
Фоны с настройкой размера (W×H) и галочкой «Сохранять пропорции 16:9».
Спрайты: перетаскиваются мышкой в любую точку, в том числе за край кадра, масштаб меняется ползунком. Галочка «Ограничить границами экрана» держит спрайт внутри кадра.
Слои: у каждого активного спрайта есть кнопки «на передний / на задний план», в коде это zorder.
Переходы для фонов и спрайтов: мгновенно, растворение (Dissolve), через чёрный экран (Fade). Если спрайт уже был на сцене, можно включить «Плавно передвинуть».
Реплики: имя персонажа (можно оставить пустым для слов автора) и текст. Кнопка «+ Пауза {w}» вставляет тег в место курсора. Быстро добавить реплику можно через Ctrl+Enter.
Музыка и звуки: каналы music, sound, stop music, настройка fade-in и fade-out.
Блок «Свой код Ren'Py» для всего, чего нет в блоках.
Сюжет
Ветки (labels): переключатель сверху, каждая ветка редактируется отдельно, между ними можно прыгать через «Переход».
Блок «Выбор» на 2–4 варианта, каждый ведёт на свою ветку и может менять переменную.
Переменные: флаги (Да/Нет) и счётчики. Блок «Условие» (If / Else) отправляет на разные ветки в зависимости от прошлых решений.
«Шанс срабатывания» (1–100 %) для любого блока. Если шанс меньше 100, в коде появляется if renpy.random.randint(1, 100) <= X:.
Блок «Скример»: резкое появление спрайта, звук и тряска hpunch.
Интерфейс игры
Главное меню: кнопки перетаскиваются по холсту куда угодно, для каждой настраиваются размер, цвет текста, цвет при наведении и прозрачность подложки. Можно выбрать фон и музыку меню. В коде это screen main_menu() с относительными координатами 0.0–1.0.
Экран настроек: галочками выбираешь, что показывать (режим экрана, громкость, скорость текста, авто-перемотка, пропуск), и настраиваешь цвета. В коде это screen preferences().
Окно диалогов: положение, размер, цвет, прозрачность, скругление, отступы, размер шрифта и своя картинка-рамка. Быстрое меню (Назад, История, Пропуск, Авто, Сохранить) можно убрать целиком или оставить только нужные кнопки. Есть поле для своего кода в screen say.
Персонажи: имя, цвет через палитру или HEX-код (например, #FF4D4D) и привязка спрайтов. В коде получается define hero = Character("Антон", color="#FF4D4D").
Плеер
Кнопка «Играть» запускает сценарий прямо в браузере: переходы, печать текста, {w}, звуки, случайные шансы, выбор и условия. В плеере работают сохранения в слоты 1–6, а также «Назад», «История», «Авто» и «Пропуск».
Как пользоваться
Загрузи фон и спрайты кнопками слева. Загруженная картинка сразу появляется на сцене.
Добавляй шаги: реплики, выбор, условия, музыку. Новый блок вставляется после выбранного.
Нужны ветки? Создай их плюсом над сценой, а в блоке «Выбор» привяжи варианты к веткам.
Хочешь проверить результат, нажми «Играть».
Настрой меню, экран настроек и окно диалогов на соответствующих вкладках.
Когда всё готово, открой вкладку «Код» справа.
Экспорт
На вкладке «Код» можно:
посмотреть любой из файлов (script.rpy, screens.rpy, options.rpy, gui.rpy) и скачать его отдельно;
задать название игры (попадает в config.name и build.name) и загрузить иконку (.png или .ico, она сохранится как gui/window_icon.png);
нажать «Скачать мод (.zip)».
Структура архива:
game/
├── script.rpy
├── screens.rpy
├── gui.rpy
├── options.rpy
├── images/
├── audio/
└── gui/
Русские буквы и пробелы в именах файлов автоматически заменяются на латиницу, иначе Ren'Py может не запуститься. Положения спрайтов по умолчанию пишутся долями от экрана (0.0–1.0), в пиксели их можно переключить галочкой.
Как перенести в Ren'Py
Отдельная игра
Установи Ren'Py SDK с renpy.org (https://www.renpy.org) и создай в лаунчере новый проект.
Замени его папку game/ содержимым архива.
Нажми «Launch Project».
Мод к чужой игре (например, «Зайчик»)
Копируй в папку game/ только script.rpy, images/ и audio/.
Файлы screens.rpy, gui.rpy и options.rpy не трогай, иначе они заменят оригинальные.
Метку start лучше переименовать и вызывать через jump из игры, чтобы не конфликтовать с оригиналом.
Сборка под платформы делается в лаунчере Ren'Py: Build Distributions (Windows, macOS, Linux), Build Android Package, Build Web Application. Для iOS нужен Mac и Xcode.
Ограничения и что стоит знать
Скрипты проверялись на синтаксис и логику генерации, но не в живом Ren'Py. Если игра не запускается, откройте окно ошибки Ren'Py и пришлите текст.
«Общая громкость» использует Preference("mixer main volume"). Если твоя версия Ren'Py его не знает, отключи эту галочку на вкладке «Экран настроек».
Шрифт один на весь проект, отдельные шрифты для каждой кнопки не поддерживаются. Предпросмотр шрифта в браузере может не работать, а в самой игре он будет.
Видеофон главного меню не поддерживается, только картинки.
Блоки «Свой код Ren'Py» плеер пропускает, он не может их выполнить. В экспортированной игре они работают.
Сохранения плеера лежат в браузере (localStorage). Если очистить данные сайта, они пропадут. В экспортированной игре сохранения обычные, средствами Ren'Py.
Шаг «Назад» в плеере возвращает на предыдущую реплику, но выбор в меню не отменяет.
Проект нигде не сохраняется автоматически: если закрыть страницу, сценарий пропадёт. Библиотека пресетов экспортируется в .json, а целиком проект сохранять пока нельзя.
